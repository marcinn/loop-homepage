# Źródła podglądów projektów

Wersja demonstracyjna używa publicznych materiałów dostępnych w sieci. Przed publikacją produkcyjną warto skopiować własne screeny do `static/img/projects/` i podmienić pola `image` w content bundle'ach.

- MaSzyna Reloaded — własne zrzuty ekranu z gry (dostarczone lokalnie), przechowywane w `static/img/projects/maszyna-reloaded/`
- a800mon — kadry z filmów demonstracyjnych na kanale YouTube @a800mon (Cheating River Raid in 120 seconds: https://www.youtube.com/watch?v=Cgu8ZdueZ6E, Cheating Montezuma in 60 seconds: https://www.youtube.com/watch?v=9Co0CPifd6Y) oraz oryginalny zrzut interfejsu monitora z repozytorium: https://github.com/a800mon/a800mon
- SimpleGamesFactory — zrzuty z nagrań wideo na X (@mjndev): klon Arkanoida (kadr z posta o fizyce brył sztywnych) https://x.com/mjndev/status/2028770808714170775 oraz Sokoban https://x.com/mjndev/status/2026395960822128826
- Godot Plugins — ilustracyjny screen pluginu Line Up Tool (MIT) z Godot Asset Library: https://godotengine.org/asset-library/asset/3165
- Godot SFX — podgląd OpenGraph repozytorium `GamesNotDeveloped/godot-sfx`: https://github.com/GamesNotDeveloped/godot-sfx
- Godot UniPlayer — podgląd OpenGraph repozytorium `GamesNotDeveloped/godot-uniplayer`: https://github.com/GamesNotDeveloped/godot-uniplayer
- Godot Weather System — miniatura wideo demonstracyjnego YouTube: https://www.youtube.com/watch?v=HVeNv4ePlgU
